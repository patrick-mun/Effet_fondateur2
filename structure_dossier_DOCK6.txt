🧬 Outils en ligne de commande
PLINK v1.9+ : ROH, IBD, HWE, MAF, LD — obligatoire dans le PATH

KING : estimation de parenté — obligatoire dans le PATH

Rscript : exécution du module Adegenet — obligatoire dans le PATH

Gamma : optionnel pour le pipeline principal, datation externe disponible via run_gamma()
